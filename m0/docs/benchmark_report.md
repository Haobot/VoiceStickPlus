## 结论

- 10 秒音频处理耗时远低于 1 秒（RTF 中位 0.016 < 0.1），**M0 通过线 A1 达标**
- 中文日常对话/朗读 CER 接近 0，**A3 达标**（参考线 < 5%）
- 中英混读技术词（Node.js / PostgreSQL / Redis 等）错误明显——这正是热词注入（提示词 B）的目标场景
- 全流程模型本地加载，无联网请求，**A2 断网可跑**（识别仅依赖本地权重与 CPU）
