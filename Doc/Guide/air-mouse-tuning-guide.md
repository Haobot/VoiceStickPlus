# 体感鼠标热调参面板说明

## 打开方式

在 VoiceStick Windows 客户端托盘菜单中选择 **“体感鼠标调参（热调参）”** 即可打开。该窗口为非模态窗口，改动即时生效，无需点击“保存”也能立刻作用到当前体感鼠标运动上；点击“保存到配置”后参数会写入 `config.toml`，下次启动依然生效。

## 控制模式

热调参面板顶部可选择控制模式，两种模式互不相同：

### 飞行摇杆模式（变化率控制，默认）

类似飞行摇杆控制飞机：手腕倾斜角度控制**光标速度的变化率（加速度）**，手腕回中后光标不会立刻停下，而是保持当前速度继续滑行；只有反向倾斜才会减速、停止或反向。

- 手腕左偏：光标持续向左加速。
- 手腕回中：光标以当前速度继续向左滑行（可通过“摩擦系数”控制滑行衰减速度）。
- 手腕右偏：光标减速、停止、再向右加速。
- 方向锁仍然生效：切换方向前必须先回到中立区死区。

### 角度控制模式

传统模式：手腕保持某个偏离角度，光标以对应速度持续移动；手腕回中时光标快速停止。

## 滑杆含义

### 控制模式

- **飞行摇杆（变化率）**：theta 映射为加速度，回中后速度保持。
- **角度控制**：theta 直接映射为速度，回中即停。

### 左右灵敏度（1–10）

控制光标在**水平方向（X 轴，yaw）**的整体响应幅度。

- 角度模式下：`gain_x = 档位 × 16`。
- 飞行摇杆模式下：同样影响加速度到速度的转换幅度。
- 默认值 5。

### 上下灵敏度（1–10）

控制光标在**垂直方向（Y 轴，pitch）**的整体响应幅度。

- 默认值 5。

### 中立区死区（1.0–10.0）

方向锁的中立区阈值。

- 默认值 3.0。
- 当手腕偏离角度 `|theta|` 小于此值时，不施加任何方向控制；
- 飞行摇杆模式下，死区内加速度为 0，速度只受摩擦影响；
- 角度模式下，死区内光标速度强制为 0。

## 飞行摇杆模式参数

### 变化率增益（10.0–500.0）

手腕偏离角度 theta 到光标加速度的增益。

- 默认值 80.0。
- 调大：同样角度下手腕倾斜导致光标加速更快，整体更“灵”。
- 调小：加速更缓和，更容易精细控制。

### 摩擦系数（0.000–0.500）

手腕回中后光标速度的衰减系数（单位 1/s）。

- 默认值 0.05。
- 调为 0：手腕回中后光标永远保持当前速度（纯飞行摇杆）。
- 调大：回中后光标更快自然停下，便于停止。
- 推荐：日常 0.03–0.10；想要明显“滑行”可选 0.01–0.03；想要快速停下可选 0.10–0.30。

### 速度上限（500–8000 像素/秒）

防止手腕长期保持大角度导致光标速度无限增长。

- 默认值 4000.0。
- 调大：跨 4K 屏或大显示器时上限更高。
- 调小：防止光标速度过快难以控制。

## 角度控制模式参数

### tau 时间常数（0.02–0.50 秒）

速度环一阶低通的时间常数，决定光标速度跟随目标速度的“顺滑程度”以及手停后的滑行距离。

- 默认值 0.05 s。
- 调小（如 0.02）：更跟手、停止更快；但陀螺仪噪声可能导致光标微抖。
- 调大（如 0.10–0.50）：更平滑、噪声被压制；手停后光标会滑行约 `3 × tau` 才完全停住。

### 微调段阈值（1.0–30.0）

三段线性增益曲线的第一个拐点。当偏离角度绝对值小于该阈值时，进入“微调段”，使用较低的微调段增益，便于精确对位。

- 默认值 15.0。
- 调大：更多日常慢转角度被纳入低增益区，整体更“稳”，但大角度响应会变慢。
- 调小：更快进入中段/甩动段，日常操作更“灵”，但精细对位容易冲过头。

### 甩动段阈值（30.0–80.0）

三段线性增益曲线的第二个拐点。当偏离角度绝对值大于该阈值时，进入“甩动段”，使用较高的甩动段增益，便于快速跨屏。

- 默认值 50.0。
- 必须大于“微调段阈值”，程序会自动保证 `微调段阈值 < 甩动段阈值`。
- 调大：需要更大的手腕角度才进入高增益甩动段，中段过渡区变宽，日常操作更线性。
- 调小：轻微甩手腕就进入高增益，跨屏更快，但可能难控制落点。

### 微调段增益（0.05–0.50）

微调段的速度倍率，作用于 `|theta| < 微调段阈值` 时。

- 默认值 0.15。
- 该倍率与灵敏度共同决定微调段速度：`v_target = theta × gain × 微调段增益`。
- 调小：微调段光标极慢，适合精确点击小按钮。
- 调大：微调段变快，日常操作更轻快，但容易过头。

### 甩动段增益（2.0–6.0）

甩动段的速度倍率，作用于 `|theta| ≥ 甩动段阈值` 时。

- 默认值 4.0。
- 调大：大角度下手腕甩动对应光标极速，跨 4K 屏更轻松。
- 调小：甩动段更保守，防止光标飞出屏幕。

### 中立区死区（1.0–10.0）

方向锁的中立区阈值，控制“光标什么时候停”以及“什么时候才能切换方向”。

- 默认值 3.0。
- 当手腕偏离角度 `|theta|` 小于此值时，光标速度强制为 0，同时释放方向锁；
- 只有手腕从中立区出发、偏离超过此值，才会锁定该方向并持续移动；
- 从右向左切换时，必须先回到中立区（光标停下），再重新出发向左，避免回转经过水平时误触发反向移动。
- 调大：中立区更宽，方向切换必须经过更明显的“回中”动作，更稳但切换延迟稍大。
- 调小：中立区更窄，更跟手，但容易在回中时因轻微过冲而误切方向。

### 中段过渡

当 `微调段阈值 ≤ |theta| < 甩动段阈值` 时，增益在“微调段增益”和“甩动段增益”之间线性插值，保证两段拐点处速度连续、无跳变。

### 反转 Y 轴

勾选后，手腕上抬时光标向下移动，下压时光标向上移动。根据个人习惯决定是否勾选。

## 按钮说明

- **保存到配置**：把当前滑杆值写入 `%APPDATA%\VoiceStick\config.toml`，持久化。
- **重置默认**：恢复出厂默认值（飞行摇杆模式、灵敏度 5/5、中立区死区 3.0、变化率增益 80、摩擦 0.05、速度上限 4000）。

## 调参建议

### 飞行摇杆模式

1. **先调灵敏度**：找到日常操作舒服的横向/纵向响应幅度。
2. **再调变化率增益**：控制手腕倾斜时光标加速的“猛度”。
3. **然后调摩擦系数**：
   - 想要明显“滑行/惯性”手感 → 0.01–0.03。
   - 想要自然停下但保留一点惯性 → 0.05–0.10。
   - 想要快速停下、接近角度控制 → 0.10–0.30。
4. **最后调中立区死区**：左右切换时容易误反向 → 调大；感觉回中后反应慢 → 调小。

### 角度控制模式

1. **先调灵敏度**。
2. **再调 tau**：感觉光标“飘”或“停不住”时先调 tau。
3. **然后调中立区死区**。
4. **最后调曲线**：
   - 觉得慢转容易冲过头 → 调大“微调段阈值”或调小“微调段增益”。
   - 觉得甩手腕跨屏不够快 → 调小“甩动段阈值”或调大“甩动段增益”。
   - 觉得日常转动速度跳跃明显 → 拉大两个阈值的间距，让中段过渡更宽。
