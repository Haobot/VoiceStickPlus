## 判定方式

口述完成后把 `~/Library/Application Support/VoiceStick/VoiceStickApp.log` 交我（或我直读），
逐条对拍：`voice_targeted result=ok/failure code=…`、`voice_edit command=…`、
`fail_stage=… bundle=…`、`midline strip` 日志与上表预期。任一红项登记返工。
