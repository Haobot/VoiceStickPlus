## 四、证据链与三个根因

### 1. A 层：设备端尾帧丢弃（BLE 吞吐不足 + 停止时 drain 排空失败）

- 判定链：
  - `Audio stream summary` 比例表：19–32 恒 ≈0.56–0.78（其中 deficit ≈ 6fps×时长），
    11–18 与 33–45 ≈1.0，窗口边界与 app 重启重连（22:51:14）后 30s 起、22:54:26 恢复；
  - BLE 同特征 notify 保序且 END（空载荷标志帧）**先于 button_up** 到达 ⇒ 缺的帧是
    **设备端没有发出**（不是空口/app 丢）；
  - 回放 ASR 消息流的音素时间轴：识别语音**语速正常（2.3–4.0 字/秒，与干净会话同分布）
    且恰好终止在最后一帧**（27 切在「上|班」中间）⇒ 收到的是**连续前缀**、尾部整段缺失，
    排除均匀丢帧（那会让语音 1.33× 变速）；
  - 固件 `audio_pipeline.c`：停录走 sentinel→drain（预算 `TX_DRAIN_TIMEOUT_MS=2000ms`），
    超时 `xQueueReset` 丢尾帧（注释明言该路径曾致「识别丢最后几个字」）；录音期链路
    ≈19/25fps 时积压按 6fps 增长，停止时 backlog≈24%×时长。
- 待补证据（需要一次带串口的复现）：`tx task exit: sent/dropped`、`drain timeout,
  discarding N packets`、`tx queue overflow` 三条哪条出现（用 `.agents/skills/usb-jtag-flash-log`
  采集即可）。桌面侧现有日志无法区分设备侧三条丢弃路径。
- 归属：**固件/BLE 传输问题，不是 targeted 功能的缺陷**；本任务红线固件零改动 ⇒ 桌面端
  只能做检测与提示（见 §五.1）。

### 2. B 层：ASR 指令轮目标词漂移

- 43/44：同一句「把升旗改成吃烤鸭」三次，前两次 升旗→分析/身体（中间结果 分奇/生气），
  第三次才对；38：成都→都（中间结果「把中路给」），且该轮实况是 8 字变体（疑「帮」开头）。
- 模式：**指令句里缺少正文语境**，低频词（升旗）在「把X改成Y」句式下向高频词漂移；
  正文轮同词识别正常（42「我要去北京看升旗。」一次成功）。
- 现成基础设施：`TencentASRVocabClient` 热词自动同步 + `sessionOptions.hotwords`。

### 3. C 层：回退粘贴污染 LastInjection（设计缺口）

- 机制：简写门控 `occurrences(target, lastInjection.remainingText)` 命中失败 → 回退普通
  文本粘贴 → `completePendingPaste` **无条件**把指令文本记为新 `LastInjection`。
- 两个后果（均有实证）：
  - 重试必败：39（识别正确的重试）对 38 的指令文本找不到「成都」；45 对 44 的文本找不到「升旗」；
  - 错误接管：26 在 25 粘贴的「把北京改成。」里命中「北京」→ 把指令文本本身改掉。
- 注意「保留旧记录救重试」不可行：字段已被粘贴的指令文本污染，旧 remaining 不再是字段
  后缀，L1 后缀校验会正确拒绝——安全模型在正常工作，问题只在**记录被覆盖后的语义**。

### 附：当前构建与日志的两个可观测性缺口

1. **execute 阶段零结果日志**：选区写入失败/读回不符/终验 unconfirmed/成功，均只有 toast
   （macOS `executeVoiceTargetedEdit` 全程无 NSLog；Windows 仅 `EnterReady("voice_targeted")`
   状态标签）→ 36/41 是否真成功无法从日志复核。§17.3 日志纪律本就允许记结果码。
2. **音频 seq 缺口未跟踪**：协议 audio_tx 带 `seq`，app 未统计缺口/deficit；一行
   `Audio stream summary` 增强（seq_gap=N）即可把「设备没发」钉死，无需串口。

## 五、按证据的优化顺序（均不放宽匹配/安全校验）

1. **P0（传输层，另立任务）**：固件侧 drain/队列/连接参数排查（需串口复现）；桌面侧可先行：
   seq 缺口统计日志 + deficit>10% 时「句尾可能缺失」提示。不改安全模型。
2. **P1（ASR 偏置）**：存在最近注入时，把 remainingText 的显著 token 作为**指令轮**热词
   （复用热词自动同步），解决 升旗/成都 类漂移。不改执行器。
3. **P1（记录污染，需拍板）**：候选方案——「解析命中简写但门控未接管」的回退粘贴给
   `LastInjection` 打 `isCommandFallback` 标记，门控对这类记录一律不接管（杜绝 26），
   可选 toast 提示用户。方案取舍（吞掉 vs 粘贴 vs 提示）涉及回退语义，须用户评审。
4. **P2（可观测性，双端同步补）**：execute 结果码日志（成功/select_fail/unconfirmed）+
   seq 缺口日志；补双端同向量测试。
5. **暂不动**：分隔符白名单（换为/变成）、助动词（帮）——今晚无样本支持，等新失败样本。
