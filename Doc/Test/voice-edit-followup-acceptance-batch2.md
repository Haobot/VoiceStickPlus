# 语音编辑批次 2 真机口述验收脚本（feat/voice-edit-followup）

> 状态：待执行。验收对象：追问「第几个」/ 整框编辑 / 上下文撤销 / 尾删光标降级 / 裸句号交叉修复。
> 通用规则同批次 1：每句等浮窗自动提交、停 2 秒；「手打」=键盘输入；每组 120 秒内完成；
> ZCode 场景做完 Cmd+A 全选 Delete 清空，**不要回车**。

## A 组：回归底线（末尾追加，行为必须与批次 1 完全一致）

| # | 应用 | 操作 / 口述 | 预期字段 | 预期提示 |
|---|---|---|---|---|
| A1 | TextEdit 新文档 | 口述「我要去北京吃烤鸭」 | `我要去北京吃烤鸭。` | 无 |
| A2 | 同上 | 口述「把北京改成上海」 | `我要去上海吃烤鸭。` | 已替换 2 个字 |
| A3 | 同上 | 口述「删掉最后两个字」 | `我要去上海吃。`（删「烤鸭」） | 已删除 2 个字 |
| A4 | ZCode 空输入框 | 口述「我要去北京吃烤鸭」再口述「删除烤鸭」 | `我要去北京吃。` | 已删除 2 个字 |

## B 组：追问「第几个」（核心新功能）

| # | 操作 / 口述 | 预期 |
|---|---|---|
| B1 | TextEdit 新文档，口述「我去北京出差北京回来」（「北京」出现两次）；再口述「把北京改成上海」 | 提示「找到 2 处「北京」，请说第几个（如“第二个”）」，字段不变 |
| B2 | 紧接着口述「第二个」 | 字段变 `我去北京出差上海回来。`（第二处被替换），**「第二个」没有上屏**，提示「已替换 2 个字」 |
| B3 | 重复 B1 场景；应答「第五个」 | 提示「只有 2 处，请说第 1 到 第 2 个」，仍在等待；再答「第一个」→ 第一处被替换 |
| B4 | 重复 B1 场景；应答「算了」 | 提示「已取消修改」，字段不变，之后正常口述不再被吞 |
| B5 | 重复 B1 场景；改说正常内容「今天天气不错」 | 正常上屏（追问自动作废，不吞话） |
| B6 | 重复 B1 场景，但在应答前**手工改掉一处「北京」**；再答「第二个」 | 提示「文本已变化，请重新说修改指令」，零修改 |
| B7 | 追问等待中说「取消」→ 再正常口述「句号」以外的词如「测试」 | 正常上屏（验证追问不会吞正常说话） |

## 判定方式

做完告诉我，我读 `VoiceStickApp.log` 对拍：`voice_targeted clarify…`、`result=ok`、
`voice_edit undo result=…`、`voice_edit tail_caret_fallback=1`、`midline_stripped=0`（E2）
等日志行，结合你报告的字段与提示逐条判定红绿。全绿则合并 main 推送（Windows 平台代码留 Windows 机）。
