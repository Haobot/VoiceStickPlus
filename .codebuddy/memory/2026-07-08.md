# 2026-07-08 工作日志

## 体感鼠标（Air Mouse）算法分析
- 分析了固件 `firmware/components/bmi270/bmi270.c` 的 `bmi270_air_mouse_poll`（50Hz：减零偏→jerk判静止EMA自愈→滞回STILL/ACTIVE→死区3dps→×SCALE(0.6)→clamp±127→BLE int16 motion）
- 桌面 `air_mouse_kin.cc` 运动学 + `voice_stick_coordinator.cc` 的 AirMouseTick/HandleMotionEvent（默认 kAngle：theta += event.dx*dt，v_target = theta×gain×factor(|theta|)）
- **核心问题（P0）**：增益曲线施加在积分量 theta 而非瞬时 omega 上，导致持续匀速转动时光标速度正反馈失控（3s 内 1.4万→34万 px/s）。修复：增益曲线改用 omega 作输入，theta 仅留作回正门控。
- 次问题（P1）：固件 int16 帧只用 ±127（浪费范围+截断甩动）、固件0.6与桌面gain双重缩放、50/60Hz dt 错配。
- 分析文档输出到 brain artifact：air-mouse-analysis.md

## 实施 P1（去双重缩放 + 放开范围 + 时间基准统一）
- 固件 `firmware/components/bmi270/bmi270.c`：`AIR_MOUSE_SCALE 0.6`→`AIR_MOUSE_REPORT_GAIN 4.0`（1dps→4 单位，分辨率提升≈6.7×）；`AIR_MOUSE_MAX_DELTA 127`→`8000`（~2000dps 甩动才饱和，不再削快速甩动）。dx 现为缩放角速率，非光标位移。
- 桌面运动学 `air_mouse_kin.h`：`AirMouseCurveParams` 默认 `15/50`→`100/333`（拐点仍≈25/83dps，物理手感不变）；`AirMouseCurveClamp` 边界放宽 `low∈[1,200]/high∈[50,800]`。
- 协调器 `voice_stick_coordinator.cc`：gain `sensitivity×320`→`×48`（增益守恒重标定，默认物理手感与前代一致）；P1(b) `stale` 时归零 `last_omega`（修复 P0 引入的"断帧仍持续移动"）；`kAirMouseOmegaStaleAge 30ms`→`80ms`（≥3×帧周期，防 50/60Hz 抖动误触发），`kAirMouseOmegaDeadzone 0.5`→`2.0`（≈0.5dps）。
- `app_config.h` 曲线阈值默认同步 `15/50`→`100/333`；`Doc/Ref/protocol.md` 澄清 motion dx/dy 为缩放角速率。
- 测试：协调器体感测试 `MotionEvent{24,0}`→`{160,0}`（40dps @ REPORT_GAIN=4，保持物理语义）；更新 `TestAirMouseGainFactorDefaultCurveMatchesLegacy`、`TestAirMouseGainFactorAcceptsCurveParams`、`TestAirMouseCurveClamp`(80→800) 断言。

## 实施 P2（死区下调 + 平滑 sigmoid 曲线）
- 固件 `firmware/components/bmi270/bmi270.c`：`AIR_MOUSE_DEADZONE_DPS 3.0f`→`1.5f`（精细对位更跟手；依赖 jerk 静止 + 静止归零 + EMA 自愈三重兜底，见 air-mouse-still-tuning.md）。
- 桌面`air_mouse_kin.cc` `AirMouseGainFactor`：三段线性 → **平滑 sigmoid** `low+(high-low)*0.5*(1+tanh((|x|-mid)/width))`，`mid=(low+high)/2`、`width=(high-low)/2`；全程 C∞ 连续、无折角。低区地板略高于 low_factor（不再是硬等于），甩动段仍趋近 high_factor。
- `air_mouse_kin.h` / `app_config.h`：`low_factor` 默认 `0.15`→`0.25`（补偿死区下调，避免微调段饿死）。协调器 gain **维持 sensitivity×48**（验证：甩动段速度与前代一致、40dps 处约 +12%、10dps 低区约 2.8× 更灵敏——符合 P2 意图，无需重标）。
- 测试：低段/中段改用 `AirMouseGainFactor(omega)` 算 v_target；`ContinuousAtLowThreshold` 改为断言"跨拐点平滑无跳变 + 值∈(low,high)"；`AcceptsCurveParams` 默认期望值 `0.15`→`0.377`；`DefaultCurveMatchesLegacy` 改写为 sigmoid 性质（中点 2.125 精确、甩动段→4.0、低区∈(0.25,0.5)、单调）；`UsesCurveParams` 比值放宽 `>2.0`→`>1.4`。
- 验证：`build_win.bat` + `ctest` 全绿（8.68s，1/1 Passed）。
- **仍需真机验证**：固件死区 1.5dps 静止微漂（jerk/EMA 兜底是否足够）、sigmoid 手感（建议热调参面板微调 low_factor/阈值）。本机无 ESP-IDF。
